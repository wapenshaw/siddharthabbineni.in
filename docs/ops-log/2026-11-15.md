## 5. Cloudflare changes made

Zone ID `b9e4533c4f14147c508add3bffdb2118`. The MCP server was added at user scope (`claude mcp add --scope user cloudflare https://mcp.cloudflare.com/mcp`).

1. **Cache rule `Blog-Cache-Everything`** (phase `http_request_cache_settings`)
   - Expression: `http.host eq "blog.siddharthabbineni.in"`.
   - Action: cache everything, edge TTL 300 s, overriding the origin.
   - Added next to the existing `Next-Static-Assets` rule, which is unchanged.
   - Verified: blog home returns `cf-cache-status: HIT`.
   - Side effect: blog changes can take up to 5 minutes to show after a deploy.
2. **WAF custom rule `Block scanner probes (dotfiles, wp, php)`** (phase `http_request_firewall_custom`, action block)
   - Blocks paths starting with `/.git`, `/.env`, `/.docker`, `/.netrc`, `/.claude`, `/.aws`, `/.ssh`, `/.vscode`, `/wp-` or `/xmlrpc`, anything containing `/.env`, and the `.php` extension.
   - Verified: `/.env`, `/.git/config`, `/wp-login.php`, `/x.php` and `/.claude/settings.json` return 403.
   - Verified: real pages, `sitemap.xml`, `feed.xml` and `robots.txt` still return 200.
   - `/.well-known/` is not matched, so it still works.

Rollback for both: Cloudflare dashboard, Caching, Cache Rules (delete `Blog-Cache-Everything`), and Security, WAF, Custom rules (delete or disable the block rule).
